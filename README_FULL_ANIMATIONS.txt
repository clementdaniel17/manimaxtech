MANIMAX TECH — FULL RESPONSIVE ANIMATED WEBSITE

This package contains all seven pages and the shared responsive and motion system.

PAGES
- index.html (Home)
- about.html
- services.html
- products.html
- projects.html
- patents.html
- contact.html

ASSETS
- assets/css/style.css: base visual design
- assets/css/responsive.css: desktop/tablet/mobile layouts
- assets/css/home-animations.css: cinematic home-page choreography
- assets/css/motion.css: shared page reveals, hover/touch and scroll controls
- assets/js/main.js: navigation, shared reveal observer, progress, back-to-top and home pointer response
- assets/images/: supplied company imagery and logo



IMPORTANT
- The seven pages remain separate; menu links navigate normally. There is no automatic page-to-page scrolling.
- Bootstrap 5.3.3 and Google Fonts are loaded from their CDNs, so internet access is needed for those external assets.
- The contact form is a front-end demonstration and needs a backend or form service to deliver messages.
- Motion respects prefers-reduced-motion.
