MANIMAX TECH — RESPONSIVE WEBSITE PACKAGE

HOW TO RUN
1. Extract this entire folder.
2. Open the extracted MANIMAX_TECH_Responsive_Website folder in VS Code.
3. Start index.html with Live Server.
4. Use the navigation links to open the other six pages.

RESPONSIVE BREAKPOINTS
- Desktop: 1101px and wider (full horizontal navigation).
- Tablet/mobile: 1100px and below (hamburger navigation).
- Small mobile: 600px and below (single-column content).

IMPORTANT
Keep the assets folder beside all HTML files. Do not move individual HTML files away from assets.
The contact form is a front-end demonstration and needs a backend/form service to deliver enquiries.
External fonts and Bootstrap are loaded from CDNs, so those resources require an internet connection.
