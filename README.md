# MANIMAX TECH — Full Responsive Animated Website

This is the complete seven-page static website package for MANIMAX TECH.

## Pages
- `index.html` — Home
- `about.html` — About Us
- `services.html` — Services
- `products.html` — Products & R&D
- `projects.html` — Projects
- `patents.html` — Patents & Publications
- `contact.html` — Contact

## Assets
- `assets/css/style.css` — Base visual design
- `assets/css/responsive.css` — Desktop, tablet and mobile layout rules
- `assets/css/home-animations.css` — Cinematic homepage hero animation system
- `assets/css/motion.css` — Shared editorial transitions and scroll reveals
- `assets/js/main.js` — Navigation, scroll reveal, header, progress, back-to-top and homepage pointer response
- `assets/images/` — Logo, founder and project/product images

## Run locally
1. Extract the ZIP file.
2. Open the extracted `MANIMAX_TECH_Full_Responsive_Animated_Website` folder in Visual Studio Code.
3. Install/use the Live Server extension if needed.
4. Right-click `index.html` and choose **Open with Live Server**.

You can also open `index.html` directly in a browser for a basic local preview. Google Fonts and Bootstrap are loaded from CDNs, so those external resources require an internet connection.

## Responsive breakpoints
- Desktop: above 1100px
- Tablet / compact navigation: 601px–1100px
- Mobile: up to 600px
- Small phones: up to 360px

The seven pages remain separate HTML documents. Navigation links open their respective pages; there is no automatic page-to-page scrolling.

## Motion and accessibility
- Homepage: staged hero entrance, orbital visual treatment, ambient motion and optional fine-pointer response.
- All pages: editorial page-heading entrance, scroll reveal, image transitions and interactive feedback.
- Mobile: compact navigation, touch-friendly controls and reduced movement.
- `prefers-reduced-motion` is respected.

## Contact form
The contact form is currently front-end demonstration behaviour only. Connect it to a backend or form service to receive enquiries.
