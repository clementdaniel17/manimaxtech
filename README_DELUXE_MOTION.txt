MANIMAX TECH — DELUXE MOTION UPDATE

This package includes the requested animation features:
1. Hero: staggered text (existing choreography), layered orbit rings, moving light points, technical grid, halo depth and logo float/parallax.
2. Scroll: directional editorial reveals (existing observer), image mask reveals and staggered cards.
3. Cards: fine-pointer desktop 3D tilt, animated perimeter highlight, image reveal; touch devices do not receive hover/tilt emulation.
4. Page transitions: short internal HTML navigation overlay; external links, anchors, mail, telephone, downloads and modified clicks are untouched.

Open this extracted folder in VS Code and run index.html with Live Server. Keep your previous folder as a backup.

Performance choices: transforms/opacity for motion, one observer for media, requestAnimationFrame for pointer tilt, no continuous scroll animation loop, reduced-motion support. Actual frame rate depends on device/browser and must be tested locally.
