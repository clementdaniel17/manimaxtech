MANIMAX TECH — PRO PAGE TRANSITIONS & ALL-PAGES MOTION

This update builds on the supplied MANIMAX_TECH_Final_Polished_Responsive_Animations project.

Included:
- Shared premium same-site HTML page transition (teal/navy wipe) on all seven pages.
- Page entrance and heading motion.
- Additional reveal targets for product galleries, specs and contact sections.
- Consistent subtle hover lift and image zoom for supported cards.
- Reduced-motion accessibility support.
- Existing content, images, navigation, and home animation files retained.

INSTALL:
1. Extract this ZIP.
2. Open the extracted MANIMAX_TECH_Final_Visual_Fix folder in VS Code.
3. Run index.html with Live Server.
4. Test navigation between Home, About, Services, Products, Projects, Patents and Contact.
5. Replace the previous project folder only after checking this version.

NOTES:
- Page transitions apply to same-site .html links. External links, downloads, new-tab links,
  modifier-clicks, and in-page anchors keep their normal behavior.
- The contact form remains a front-end demonstration; this update does not connect a mail backend.
- For users who request reduced motion, the page-wipe and nonessential entrance animations are disabled.
