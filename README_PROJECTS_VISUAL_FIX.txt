MANIMAX TECH — Project Gallery Visual Fix

This package is based on the latest working website folder and keeps all seven pages and existing assets.

Main correction:
- Projects page now uses a consistent 2-column gallery on desktop and tablet, and a single column on phones.
- All project photos use consistent aspect-ratio frames and object-fit cropping.
- Project cards have consistent vertical layout; titles, descriptions and links sit below the images.
- Removed project cards from the JS scroll-reveal observer so card content cannot remain hidden if an observer event is missed.
- Hover effects are limited to subtle image zoom and shadow changes.

Run:
1. Extract this ZIP into a NEW folder.
2. Open that folder in VS Code.
3. Right-click index.html > Open with Live Server.
4. Open projects.html and test desktop, tablet and mobile widths.

No project information or image files were invented or replaced. Existing four project photos and descriptions are retained.
