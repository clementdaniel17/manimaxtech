MANIMAX TECH — HOME PAGE ANIMATION PHASE 1

Direction: Orbit / Passion inspired, editorial and smooth, with high cinematic expression.

Included in this phase:
- Staggered hero typography entrance
- Ambient orbital rings and subtle halo movement
- Floating company emblem with desktop pointer depth response
- Scroll-triggered section and card reveals on the home page
- Refined product/capability card hover and image zoom
- CTA and statement-section atmospheric accents
- Shared navigation, sticky header, progress line and back-to-top interactions
- Responsive motion tuning and reduced-motion accessibility

The home page uses assets/css/home-animations.css. The other six pages retain their current layouts and shared navigation utilities; their page-specific animation pass comes next.

Installation: Extract the folder and open it in VS Code. Run index.html with Live Server. Keep the assets folder structure unchanged.

Important: This is a separate seven-page site. Navigation links remain normal page links. There is no automatic page-to-page scroll navigation. The contact form remains a front-end demo until connected to a backend or form service.
